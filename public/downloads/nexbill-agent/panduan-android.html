NEXBILL Relay Agent — Pakai HP Android (tanpa PC)

Tidak punya PC di outlet? HP Android bisa menggantikannya. HP ini menjadi "jembatan" antara NEXBILL dan Android TV di outlet. Ikuti langkah di bawah pelan-pelan — semua perintah tinggal disalin, tidak perlu mengetik. Cukup sekali per outlet.

⚡ Ringkas — sudah paham teknologi

  1. Minta token (tombol di bawah) → token masuk ke Chat/Bantuan.
  2. Pasang Termux + Termux:Boot dari F-Droid (bukan Play Store), buka Termux:Boot sekali.
  3. Tempel di Termux:
    apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash
  4. Pilih bahasa → tempel token → tunggu status Relay Agent online.
  5. Tiap TV: Developer options › Network debugging ON → di Termux (NEW SESSION) ketik nexbill-tv <IP TV> → Allow di TV (centang Always allow).
    nexbill-tv 192.168.1.50
  6. HP: baterai Termux "Tidak dibatasi", kunci Termux di Recent apps, notifikasi Termux → Acquire wakelock.
  7. Kontrol Perangkat › Tambah Perangkat › TV (Android/Google TV) › isi nama & IP TV → Simpan → tes Nyalakan/Matikan.

0Siapkan HP

  • HP Android 7 ke atas — sebaiknya HP bekas khusus untuk ini, bukan HP pribadi yang dibawa pulang.
  • Tersambung ke WiFi yang SAMA dengan TV di outlet, dan selalu berada di outlet.
  • Selalu dicas (colok charger terus) dan layar boleh mati.

1Minta Token

Tekan tombol di bawah. Token dikirim ke menu Chat/Bantuan. Buka menu itu di HP yang akan dipakai, supaya token mudah disalin nanti.

2Pasang aplikasi Termux dan Termux:Boot

Pernah memasang Termux dari Play Store? Hapus dulu (uninstall). Termux versi Play Store sudah lama dan tidak cocok dengan Termux:Boot dari F-Droid.

  1. Di HP yang akan dipakai, buka link Termux di bawah dengan Chrome.

    Termux: https://f-droid.org/packages/com.termux/
    Termux:Boot: https://f-droid.org/packages/com.termux.boot/

  2. Gulir ke bagian "Packages" / "Paket", lalu tekan "Download APK" / "Unduh APK" pada versi PALING ATAS. Jangan tekan tombol besar "Download F-Droid".
  3. Setelah unduhan selesai, tekan "Buka" (atau buka file .apk dari notifikasi / folder Download).
  4. Kalau muncul "Untuk keamanan, HP Anda tidak diizinkan memasang aplikasi tidak dikenal dari sumber ini": tekan Setelan, aktifkan "Izinkan dari sumber ini", lalu kembali dan tekan Instal.
  5. Kalau Google Play Protect memperingatkan, pilih "Detail lainnya" → "Tetap instal". Termux dari F-Droid adalah aplikasi resmi yang aman.
  6. Ulangi langkah yang sama untuk Termux:Boot (link kedua).
  7. Buka aplikasi Termux:Boot SEKALI (cukup dibuka lalu ditutup), lalu buka Termux dan tunggu sampai muncul tanda $ di layar hitam.

3Salin satu perintah ke Termux

Tekan Salin di bawah. Buka Termux, tekan lama di layar hitam, pilih Paste/Tempel, lalu tekan Enter. Tunggu 2–5 menit sampai muncul pilihan bahasa. Kalau ditanya "Do you want to continue? [Y/n]", ketik y lalu Enter.

apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash

Selesai kalau muncul tulisan "[5/5] Selesai dipasang" lalu "Pilih bahasa / Choose language". Muncul tulisan "WARNING: apt does not have a stable CLI interface"? Itu normal, abaikan saja.

4Pilih bahasa dan tempel token

  1. Di Termux ketik angka bahasa lalu Enter (1 = Bahasa Indonesia, atau langsung Enter).
  2. Ambil token: buka NEXBILL di Chrome HP ini → menu Chat/Bantuan → pesan berisi token → tekan lama teks token → Salin.
  3. Kembali ke Termux (tulisan "Masukkan Agent Token" masih tampil), tekan lama layar hitam → Paste → Enter.
  4. Berhasil kalau muncul "Terhubung … Menunggu perintah dari NEXBILL" dan status Relay Agent di halaman ini menjadi online.

5Sambungkan setiap TV (sekali per TV)

  1. Di TV: Settings → Device Preferences (atau System) → About → tekan baris "Build" 7 kali sampai muncul "You are now a developer".
  2. Kembali ke Device Preferences → Developer options → aktifkan "Network debugging" (atau "ADB debugging"). Catat IP TV — biasanya tampil di bawahnya, mis. 192.168.1.23. Tidak terlihat? Lihat di Settings → Network & Internet → nama WiFi.
  3. Di HP: buka Termux, geser dari tepi KIRI layar → tekan NEW SESSION, lalu ketik perintah di bawah dengan IP TV Anda dan Enter.
    nexbill-tv 192.168.1.50
  4. Lihat layar TV: muncul "Allow USB debugging?" / "Allow network debugging?" — centang "Always allow from this computer", lalu pilih Allow/OK. Ulangi Langkah 5 untuk setiap TV.

Ganti 192.168.1.50 dengan IP TV Anda. Berhasil kalau tertulis "device" di samping IP TV.

6Supaya tidak dimatikan oleh HP (penting!)

  • Pengaturan → Aplikasi → Termux → Baterai → pilih "Tidak dibatasi" / "Unrestricted". Lakukan juga untuk Termux:Boot.
  • Buka daftar aplikasi terbaru, tekan lama Termux, lalu pilih Kunci (ikon gembok) supaya tidak ikut tertutup saat "Bersihkan semua".
  • Jangan hapus notifikasi Termux — itu tanda agent sedang berjalan.
  • Tarik panel notifikasi, cari notifikasi Termux, lalu tekan "Acquire wakelock" supaya HP tidak menidurkan agent saat layar mati.
  • Xiaomi / Redmi / POCO: Setelan → Aplikasi → Kelola aplikasi → Termux → aktifkan "Mulai otomatis", lalu Penghemat baterai → "Tanpa batasan".
  • OPPO / realme / vivo: Setelan → Aplikasi → Termux → Penggunaan baterai → aktifkan "Izinkan aktivitas latar belakang" dan "Izinkan mulai otomatis".
  • Samsung: Setelan → Aplikasi → Termux → Baterai → "Tidak dibatasi". Pastikan Termux tidak masuk daftar "Aplikasi tidur" di Setelan → Baterai → Batas penggunaan latar belakang.

7Tambahkan TV di NEXBILL

Kembali ke halaman ini, klik "Tambah Perangkat", pilih protokol "TV (Android/Google TV)", isi nama dan IP TV dari Langkah 5, lalu Simpan. Selesai — TV bisa dinyalakan/dimatikan dari dashboard ini.

✓ Cara cek semuanya berjalan

  • Di halaman ini, status Relay Agent tertulis online.
  • Di HP ada notifikasi Termux ("1 session"). Kalau hilang, buka Termux dan ketik nexbill.
  • Di daftar perangkat di bawah, tombol Nyalakan/Matikan pada TV benar-benar menyalakan dan mematikan TV.

⚠ Kalau ada masalah

  • Muncul "CANNOT LINK EXECUTABLE curl" atau "cannot locate symbol": paket Termux belum diperbarui semua. Di Termux ketik: apt update && yes | apt full-upgrade — tunggu selesai, lalu tempel lagi perintah Langkah 3.
  • Relay Agent "offline": buka Termux, ketik nexbill lalu Enter.
  • TV tidak merespons: pastikan TV menyala/standby dan di WiFi yang sama, lalu di Termux ketik nexbill-tv diikuti IP TV.
  • Setelah HP dinyalakan ulang, agent menyala sendiri (Termux:Boot). Kalau tidak, buka Termux dan ketik nexbill.
  • Agent memperbarui diri otomatis (diperiksa tiap 6 jam, dipasang pukul 03.00–06.00). Ingin langsung versi terbaru? Di Termux ketik nexbill-update — token tidak perlu dimasukkan ulang.
  • Masih bingung? Kirim foto layar Termux ke menu Chat/Bantuan — tim NEXBILL akan membantu.

NEXBILL Relay Agent — Use an Android phone (no PC)

No PC at the outlet? An Android phone can replace it. The phone becomes the "bridge" between NEXBILL and the Android TVs at the outlet. Follow the steps below slowly — every command can be copied, no typing needed. Only once per outlet.

⚡ Quick — already tech-savvy

  1. Request a token (button below) → it arrives in Chat/Help.
  2. Install Termux + Termux:Boot from F-Droid (not the Play Store), open Termux:Boot once.
  3. Paste into Termux:
    apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash
  4. Choose a language → paste the token → wait until the Relay Agent is online.
  5. Each TV: Developer options › Network debugging ON → in Termux (NEW SESSION) type nexbill-tv <TV IP> → Allow on the TV (tick Always allow).
    nexbill-tv 192.168.1.50
  6. Phone: Termux battery "Unrestricted", lock Termux in Recent apps, Termux notification → Acquire wakelock.
  7. Device Control › Add Device › TV (Android/Google TV) › enter name & TV IP → Save → test On/Off.

0Prepare the phone

  • Android 7 or newer — ideally a spare phone dedicated to this, not a personal phone that goes home.
  • Connected to the SAME WiFi as the TVs, and always kept at the outlet.
  • Always charging (keep the charger plugged in); the screen can be off.

1Request a Token

Press the button below. The token is sent to the Chat/Help menu. Open that menu on the phone you'll use so the token is easy to copy later.

2Install the Termux and Termux:Boot apps

Installed Termux from the Play Store before? Uninstall it first. The Play Store version is outdated and does not work with Termux:Boot from F-Droid.

  1. On the phone you will use, open the Termux link below in Chrome.

    Termux: https://f-droid.org/packages/com.termux/
    Termux:Boot: https://f-droid.org/packages/com.termux.boot/

  2. Scroll to the "Packages" section and tap "Download APK" on the TOP version. Do not tap the big "Download F-Droid" button.
  3. When the download finishes, tap "Open" (or open the .apk file from the notification / Downloads folder).
  4. If you see "For your security, your phone is not allowed to install unknown apps from this source": tap Settings, turn on "Allow from this source", then go back and tap Install.
  5. If Google Play Protect warns you, choose "More details" → "Install anyway". Termux from F-Droid is the official, safe app.
  6. Repeat the same steps for Termux:Boot (the second link).
  7. Open the Termux:Boot app ONCE (just open and close it), then open Termux and wait until the $ sign appears on the black screen.

3Copy one command into Termux

Tap Copy below. Open Termux, long-press the black screen, choose Paste, then press Enter. Wait 2–5 minutes until the language choice appears. If asked "Do you want to continue? [Y/n]", type y and press Enter.

apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash

Done when you see "[5/5] Installed" followed by "Choose language". Seeing "WARNING: apt does not have a stable CLI interface"? That is normal — ignore it.

4Choose a language and paste the token

  1. In Termux type the language number and press Enter (2 = English).
  2. Get the token: open NEXBILL in Chrome on this phone → Chat/Help menu → the message with the token → long-press the token text → Copy.
  3. Go back to Termux ("Enter the Agent Token" is still shown), long-press the black screen → Paste → Enter.
  4. It worked when you see "Connected … Waiting for commands from NEXBILL" and the Relay Agent status on this page turns online.

5Connect each TV (once per TV)

  1. On the TV: Settings → Device Preferences (or System) → About → press the "Build" line 7 times until "You are now a developer" appears.
  2. Go back to Device Preferences → Developer options → turn on "Network debugging" (or "ADB debugging"). Note the TV IP — usually shown below it, e.g. 192.168.1.23. Not shown? Check Settings → Network & Internet → the WiFi name.
  3. On the phone: open Termux, swipe in from the LEFT edge → tap NEW SESSION, then type the command below with your TV's IP and press Enter.
    nexbill-tv 192.168.1.50
  4. Look at the TV: "Allow USB debugging?" / "Allow network debugging?" appears — tick "Always allow from this computer", then choose Allow/OK. Repeat Step 5 for every TV.

Replace 192.168.1.50 with your TV's IP. It worked if "device" appears next to the TV's IP.

6So the phone doesn't kill it (important!)

  • Settings → Apps → Termux → Battery → choose "Unrestricted". Do the same for Termux:Boot.
  • Open the recent-apps list, long-press Termux and choose Lock (padlock icon) so it isn't closed by "Clear all".
  • Don't dismiss the Termux notification — it shows the agent is running.
  • Pull down the notification panel, find the Termux notification and tap "Acquire wakelock" so the phone does not put the agent to sleep when the screen is off.
  • Xiaomi / Redmi / POCO: Settings → Apps → Manage apps → Termux → turn on "Autostart", then Battery saver → "No restrictions".
  • OPPO / realme / vivo: Settings → Apps → Termux → Battery usage → turn on "Allow background activity" and "Allow auto launch".
  • Samsung: Settings → Apps → Termux → Battery → "Unrestricted". Make sure Termux is not in "Sleeping apps" under Settings → Battery → Background usage limits.

7Add the TV in NEXBILL

Come back to this page, click "Add Device", choose the "TV (Android/Google TV)" protocol, enter a name and the TV's IP from Step 5, then Save. Done — the TV can now be turned on/off from this dashboard.

✓ How to check everything works

  • On this page, the Relay Agent status shows online.
  • The phone shows a Termux notification ("1 session"). If it is gone, open Termux and type nexbill.
  • In the device list below, the On/Off buttons on the TV really turn the TV on and off.

⚠ If something goes wrong

  • "CANNOT LINK EXECUTABLE curl" or "cannot locate symbol" appears: Termux packages are only partly updated. In Termux type: apt update && yes | apt full-upgrade — wait for it to finish, then paste the Step 3 command again.
  • Relay Agent "offline": open Termux, type nexbill and press Enter.
  • TV not responding: make sure the TV is on/standby and on the same WiFi, then in Termux type nexbill-tv followed by the TV's IP.
  • After the phone restarts, the agent starts on its own (Termux:Boot). If not, open Termux and type nexbill.
  • The agent updates itself automatically (checked every 6 hours, installed between 03:00–06:00). Want the latest version right away? In Termux type nexbill-update — no need to re-enter the token.
  • Still stuck? Send a screenshot of Termux to the Chat/Help menu — the NEXBILL team will help.

ไม่มี PC ที่ร้าน? ใช้มือถือ Android แทนได้ มือถือเครื่องนี้จะเป็น "สะพาน" ระหว่าง NEXBILL กับ Android TV ในร้าน ทำตามขั้นตอนด้านล่างช้าๆ — ทุกคำสั่งคัดลอกได้ ไม่ต้องพิมพ์ ทำครั้งเดียวต่อร้าน

⚡ ย่อ — คุ้นเคยเทคโนโลยีแล้ว

  1. ขอโทเคน (ปุ่มด้านล่าง) → โทเคนจะอยู่ในแชต/ช่วยเหลือ
  2. ติดตั้ง Termux + Termux:Boot จาก F-Droid (ไม่ใช่ Play Store) แล้วเปิด Termux:Boot หนึ่งครั้ง

  7. ควบคุมอุปกรณ์ › เพิ่มอุปกรณ์ › ทีวี (Android/Google TV) › ใส่ชื่อและ IP ทีวี → บันทึก → ทดสอบเปิด/ปิด

0เตรียมมือถือ

  • Android 7 ขึ้นไป — ควรเป็นมือถือเครื่องเก่าที่ใช้งานนี้โดยเฉพาะ ไม่ใช่มือถือส่วนตัวที่นำกลับบ้าน
  • เชื่อมต่อ WiFi เดียวกับทีวีในร้าน และอยู่ที่ร้านตลอด
  • ชาร์จไฟตลอดเวลา (เสียบสายชาร์จไว้) หน้าจอดับได้

1ขอโทเคน

กดปุ่มด้านล่าง โทเคนจะถูกส่งไปที่เมนูแชท/ช่วยเหลือ เปิดเมนูนั้นบนมือถือเครื่องที่จะใช้ เพื่อให้คัดลอกโทเคนได้ง่าย

2ติดตั้งแอป Termux และ Termux:Boot

เคยติดตั้ง Termux จาก Play Store? ถอนการติดตั้งก่อน เวอร์ชัน Play Store เก่าและใช้กับ Termux:Boot จาก F-Droid ไม่ได้

  1. บนมือถือที่จะใช้ เปิดลิงก์ Termux ด้านล่างด้วย Chrome

    Termux: https://f-droid.org/packages/com.termux/
    Termux:Boot: https://f-droid.org/packages/com.termux.boot/

  2. เลื่อนลงไปที่ส่วน "Packages" แล้วกด "Download APK" ที่เวอร์ชันบนสุด อย่ากดปุ่มใหญ่ "Download F-Droid"
  3. เมื่อดาวน์โหลดเสร็จ กด "เปิด" (หรือเปิดไฟล์ .apk จากการแจ้งเตือน / โฟลเดอร์ Download)
  4. ถ้าขึ้นว่า "เพื่อความปลอดภัย โทรศัพท์ไม่อนุญาตให้ติดตั้งแอปที่ไม่รู้จักจากแหล่งนี้" ให้กดการตั้งค่า เปิด "อนุญาตจากแหล่งนี้" แล้วย้อนกลับมากดติดตั้ง
  5. ถ้า Google Play Protect เตือน ให้เลือก "รายละเอียดเพิ่มเติม" → "ติดตั้งต่อไป" Termux จาก F-Droid เป็นแอปทางการที่ปลอดภัย
  6. ทำขั้นตอนเดิมซ้ำสำหรับ Termux:Boot (ลิงก์ที่สอง)
  7. เปิดแอป Termux:Boot หนึ่งครั้ง (เปิดแล้วปิด) จากนั้นเปิด Termux และรอจนเห็นเครื่องหมาย $ บนหน้าจอสีดำ

3คัดลอกคำสั่งเดียวไปที่ Termux

กดคัดลอกด้านล่าง เปิด Termux กดค้างที่หน้าจอสีดำ เลือก Paste แล้วกด Enter รอ 2–5 นาทีจนมีตัวเลือกภาษา ถ้าถาม "Do you want to continue? [Y/n]" ให้พิมพ์ y แล้วกด Enter

apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash

เสร็จเมื่อเห็น "[5/5]" ตามด้วย "Choose language" ถ้าเห็น "WARNING: apt does not have a stable CLI interface" เป็นเรื่องปกติ ไม่ต้องสนใจ

4เลือกภาษาและวางโทเคน

  1. ใน Termux พิมพ์หมายเลขภาษาแล้วกด Enter (4 = ภาษาไทย)
  2. รับโทเคน: เปิด NEXBILL ใน Chrome บนมือถือนี้ → เมนูแชต/ช่วยเหลือ → ข้อความที่มีโทเคน → กดค้างที่ข้อความโทเคน → คัดลอก
  3. กลับไปที่ Termux (ยังแสดง "ใส่ Agent Token") กดค้างที่หน้าจอสีดำ → Paste → Enter
  4. สำเร็จเมื่อขึ้น "เชื่อมต่อแล้ว … รอคำสั่งจาก NEXBILL" และสถานะ Relay Agent ในหน้านี้เป็นออนไลน์

5เชื่อมต่อทีวีแต่ละเครื่อง (ครั้งเดียวต่อทีวี)

  1. ที่ทีวี: Settings → Device Preferences (หรือ System) → About → กดบรรทัด "Build" 7 ครั้งจนขึ้น "You are now a developer"
  2. กลับไปที่ Device Preferences → Developer options → เปิด "Network debugging" (หรือ "ADB debugging") จด IP ของทีวี — มักแสดงอยู่ด้านล่าง เช่น 192.168.1.23 ถ้าไม่เห็น ดูที่ Settings → Network & Internet → ชื่อ WiFi
  3. ที่มือถือ: เปิด Termux ปัดจากขอบซ้ายของจอ → กด NEW SESSION แล้วพิมพ์คำสั่งด้านล่างพร้อม IP ทีวีของคุณ แล้วกด Enter
    nexbill-tv 192.168.1.50
  4. ดูที่หน้าจอทีวี: จะขึ้น "Allow USB debugging?" / "Allow network debugging?" — ติ๊ก "Always allow from this computer" แล้วเลือก Allow/OK ทำขั้นตอนที่ 5 ซ้ำกับทีวีทุกเครื่อง

เปลี่ยน 192.168.1.50 เป็น IP ทีวีของคุณ สำเร็จถ้ามีคำว่า "device" ข้าง IP ทีวี

6เพื่อไม่ให้มือถือปิดแอป (สำคัญ!)

  • การตั้งค่า → แอป → Termux → แบตเตอรี่ → เลือก "ไม่จำกัด" / "Unrestricted" ทำแบบเดียวกันกับ Termux:Boot
  • เปิดรายการแอปล่าสุด กดค้างที่ Termux แล้วเลือกล็อก (ไอคอนแม่กุญแจ) เพื่อไม่ให้ถูกปิดเมื่อกด "ล้างทั้งหมด"
  • อย่าปัดการแจ้งเตือนของ Termux ทิ้ง — นั่นคือสัญญาณว่าเอเจนต์กำลังทำงาน
  • ดึงแผงการแจ้งเตือนลง หาการแจ้งเตือนของ Termux แล้วกด "Acquire wakelock" เพื่อไม่ให้มือถือพักเอเจนต์ตอนจอดับ
  • Xiaomi / Redmi / POCO: การตั้งค่า → แอป → จัดการแอป → Termux → เปิด "เริ่มอัตโนมัติ" แล้วไปที่ตัวประหยัดแบตเตอรี่ → "ไม่มีข้อจำกัด"
  • OPPO / realme / vivo: การตั้งค่า → แอป → Termux → การใช้แบตเตอรี่ → เปิด "อนุญาตกิจกรรมเบื้องหลัง" และ "อนุญาตเริ่มอัตโนมัติ"
  • Samsung: การตั้งค่า → แอป → Termux → แบตเตอรี่ → "ไม่จำกัด" ตรวจว่า Termux ไม่อยู่ใน "แอปที่หลับ" ที่ การตั้งค่า → แบตเตอรี่ → การจำกัดการใช้งานเบื้องหลัง

7เพิ่มทีวีใน NEXBILL

กลับมาที่หน้านี้ คลิก "เพิ่มอุปกรณ์" เลือกโปรโตคอล "ทีวี (Android/Google TV)" กรอกชื่อและ IP ทีวีจากขั้นตอนที่ 5 แล้วบันทึก เสร็จแล้ว — ทีวีสามารถเปิด/ปิดได้จากแดชบอร์ดนี้

✓ วิธีตรวจว่าทุกอย่างทำงาน

  • ในหน้านี้ สถานะ Relay Agent เป็นออนไลน์
  • มือถือมีการแจ้งเตือน Termux ("1 session") ถ้าหายไป เปิด Termux แล้วพิมพ์ nexbill
  • ในรายการอุปกรณ์ด้านล่าง ปุ่มเปิด/ปิดของทีวีเปิดและปิดทีวีได้จริง

⚠ หากมีปัญหา

  • ขึ้น "CANNOT LINK EXECUTABLE curl" หรือ "cannot locate symbol": แพ็กเกจ Termux อัปเดตไม่ครบ ใน Termux พิมพ์: apt update && yes | apt full-upgrade — รอจนเสร็จ แล้ววางคำสั่งขั้นตอนที่ 3 อีกครั้ง
  • Relay Agent "ออฟไลน์": เปิด Termux พิมพ์ nexbill แล้วกด Enter
  • ทีวีไม่ตอบสนอง: ตรวจสอบว่าทีวีเปิด/สแตนด์บายและอยู่ WiFi เดียวกัน แล้วพิมพ์ nexbill-tv ตามด้วย IP ทีวีใน Termux
  • หลังรีสตาร์ทมือถือ เอเจนต์จะเริ่มเอง (Termux:Boot) ถ้าไม่เริ่ม ให้เปิด Termux แล้วพิมพ์ nexbill
  • เอเจนต์อัปเดตตัวเองอัตโนมัติ (ตรวจทุก 6 ชั่วโมง ติดตั้งช่วง 03.00–06.00) ต้องการเวอร์ชันล่าสุดทันที? พิมพ์ nexbill-update ใน Termux — ไม่ต้องใส่โทเคนใหม่
  • ยังสับสน? ส่งภาพหน้าจอ Termux ไปที่เมนูแชท/ช่วยเหลือ — ทีม NEXBILL จะช่วย

NEXBILL Relay Agent — Gumamit ng Android phone (walang PC)

Walang PC sa outlet? Puwedeng pumalit ang Android phone. Ang phone ang magsisilbing "tulay" ng NEXBILL at ng mga Android TV sa outlet. Sundin nang dahan-dahan ang mga hakbang — kokopyahin lang ang bawat command, walang ita-type. Isang beses lang bawat outlet.

⚡ Maikli — sanay na sa teknolohiya

  1. Humingi ng token (button sa ibaba) → darating sa Chat/Tulong.
  2. I-install ang Termux + Termux:Boot mula sa F-Droid (hindi Play Store), buksan ang Termux:Boot nang isang beses.
  3. I-paste sa Termux:
    apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash
  4. Pumili ng wika → i-paste ang token → hintaying mag-online ang Relay Agent.
  5. Bawat TV: Developer options › Network debugging ON → sa Termux (NEW SESSION) i-type ang nexbill-tv <IP ng TV> → Allow sa TV (i-tick ang Always allow).
    nexbill-tv 192.168.1.50
  6. Phone: Termux battery "Unrestricted", i-lock ang Termux sa Recent apps, Termux notification → Acquire wakelock.
  7. Device Control › Add Device › TV (Android/Google TV) › ilagay ang pangalan at IP ng TV → Save → subukan ang On/Off.

0Ihanda ang phone

  • Android 7 pataas — mas mabuti kung lumang phone na para rito lang, hindi personal na phone na iniuuwi.
  • Nakakonekta sa PAREHONG WiFi ng mga TV, at laging nasa outlet.
  • Laging naka-charge (nakasaksak ang charger); puwedeng patay ang screen.

1Humingi ng Token

Pindutin ang button sa ibaba. Ipapadala ang token sa Chat/Tulong menu. Buksan ang menu na iyon sa phone na gagamitin para madaling makopya ang token.

2I-install ang Termux at Termux:Boot

Nag-install na ng Termux mula sa Play Store? I-uninstall muna. Luma na ang bersyon sa Play Store at hindi tugma sa Termux:Boot mula sa F-Droid.

  1. Sa phone na gagamitin, buksan ang Termux link sa ibaba gamit ang Chrome.

    Termux: https://f-droid.org/packages/com.termux/
    Termux:Boot: https://f-droid.org/packages/com.termux.boot/

  2. Mag-scroll sa bahaging "Packages" at pindutin ang "Download APK" sa PINAKAITAAS na bersyon. Huwag pindutin ang malaking button na "Download F-Droid".
  3. Pagkatapos ng download, pindutin ang "Open" (o buksan ang .apk file mula sa notification / Downloads folder).
  4. Kapag lumabas ang "For your security, your phone is not allowed to install unknown apps from this source": pindutin ang Settings, i-on ang "Allow from this source", bumalik at pindutin ang Install.
  5. Kapag nagbabala ang Google Play Protect, piliin ang "More details" → "Install anyway". Opisyal at ligtas ang Termux mula sa F-Droid.
  6. Ulitin ang parehong hakbang para sa Termux:Boot (ang ikalawang link).
  7. Buksan ang Termux:Boot nang ISANG beses (buksan lang at isara), saka buksan ang Termux at hintaying lumabas ang $ sa itim na screen.

3Kopyahin ang isang command sa Termux

Pindutin ang Kopyahin sa ibaba. Buksan ang Termux, pindutin nang matagal ang itim na screen, piliin ang Paste, saka pindutin ang Enter. Maghintay ng 2–5 minuto hanggang lumabas ang pagpili ng wika. Kapag tinanong ng "Do you want to continue? [Y/n]", i-type ang y at pindutin ang Enter.

apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash

Tapos na kapag lumabas ang "[5/5]" na sinusundan ng "Choose language". May "WARNING: apt does not have a stable CLI interface"? Normal iyon — huwag pansinin.

4Pumili ng wika at i-paste ang token

  1. Sa Termux i-type ang numero ng wika at pindutin ang Enter (5 = Filipino).
  2. Kunin ang token: buksan ang NEXBILL sa Chrome ng phone na ito → menu na Chat/Tulong → ang mensaheng may token → pindutin nang matagal ang token → Copy.
  3. Bumalik sa Termux (nakikita pa ang "Ilagay ang Agent Token"), pindutin nang matagal ang itim na screen → Paste → Enter.
  4. Tagumpay kapag lumabas ang "Nakakonekta … Naghihintay ng utos mula sa NEXBILL" at naging online ang Relay Agent sa page na ito.

5Ikonekta ang bawat TV (isang beses bawat TV)

  1. Sa TV: Settings → Device Preferences (o System) → About → pindutin ang "Build" nang 7 beses hanggang lumabas ang "You are now a developer".
  2. Bumalik sa Device Preferences → Developer options → i-on ang "Network debugging" (o "ADB debugging"). Itala ang IP ng TV — karaniwang nasa ilalim nito, hal. 192.168.1.23. Wala? Tingnan sa Settings → Network & Internet → pangalan ng WiFi.
  3. Sa phone: buksan ang Termux, mag-swipe mula sa KALIWANG gilid → pindutin ang NEW SESSION, saka i-type ang utos sa ibaba gamit ang IP ng TV at pindutin ang Enter.
    nexbill-tv 192.168.1.50
  4. Tingnan ang TV: lalabas ang "Allow USB debugging?" / "Allow network debugging?" — i-tick ang "Always allow from this computer", saka piliin ang Allow/OK. Ulitin ang Hakbang 5 para sa bawat TV.

Palitan ang 192.168.1.50 ng IP ng TV mo. Tagumpay kung may "device" sa tabi ng IP ng TV.

6Para hindi ito patayin ng phone (mahalaga!)

  • Settings → Apps → Termux → Battery → piliin ang "Unrestricted". Gawin din sa Termux:Boot.
  • Buksan ang listahan ng recent apps, pindutin nang matagal ang Termux at piliin ang Lock (icon ng padlock) para hindi ito masara ng "Clear all".
  • Huwag alisin ang notification ng Termux — tanda iyon na tumatakbo ang agent.
  • Hilahin pababa ang notifications, hanapin ang notification ng Termux at pindutin ang "Acquire wakelock" para hindi patulugin ng phone ang agent kapag patay ang screen.
  • Xiaomi / Redmi / POCO: Settings → Apps → Manage apps → Termux → i-on ang "Autostart", saka Battery saver → "No restrictions".
  • OPPO / realme / vivo: Settings → Apps → Termux → Battery usage → i-on ang "Allow background activity" at "Allow auto launch".
  • Samsung: Settings → Apps → Termux → Battery → "Unrestricted". Siguraduhing wala ang Termux sa "Sleeping apps" sa Settings → Battery → Background usage limits.

7Idagdag ang TV sa NEXBILL

Bumalik sa page na ito, i-click ang "Magdagdag ng Device", piliin ang protocol na "TV (Android/Google TV)", ilagay ang pangalan at IP ng TV mula sa Hakbang 5, pagkatapos I-save. Tapos na — puwede nang i-on/off ang TV mula sa dashboard na ito.

✓ Paano tingnan kung gumagana lahat

  • Sa page na ito, online ang status ng Relay Agent.
  • May notification ng Termux sa phone ("1 session"). Kung wala, buksan ang Termux at i-type ang nexbill.
  • Sa listahan ng device sa ibaba, talagang binubuksan at pinapatay ng On/Off button ang TV.

⚠ Kung may problema

  • Lumabas ang "CANNOT LINK EXECUTABLE curl" o "cannot locate symbol": hindi pa lahat na-update ang mga package ng Termux. Sa Termux i-type: apt update && yes | apt full-upgrade — hintaying matapos, saka i-paste ulit ang utos sa Hakbang 3.
  • Relay Agent "offline": buksan ang Termux, i-type ang nexbill at pindutin ang Enter.
  • Hindi tumutugon ang TV: siguraduhing naka-on/standby ang TV at nasa parehong WiFi, tapos sa Termux i-type ang nexbill-tv kasunod ang IP ng TV.
  • Pagka-restart ng phone, kusang mag-start ang agent (Termux:Boot). Kung hindi, buksan ang Termux at i-type ang nexbill.
  • Kusang nag-a-update ang agent (sinusuri tuwing 6 na oras, ini-install sa 03:00–06:00). Gusto agad ang pinakabago? Sa Termux i-type ang nexbill-update — hindi na kailangang ilagay muli ang token.
  • Nalilito pa rin? Magpadala ng screenshot ng Termux sa Chat/Tulong menu — tutulong ang NEXBILL team.

NEXBILL Relay Agent — Dùng điện thoại Android (không cần PC)

Không có máy tính ở cửa hàng? Điện thoại Android có thể thay thế. Điện thoại này là "cầu nối" giữa NEXBILL và Android TV ở cửa hàng. Làm theo từng bước bên dưới — mọi lệnh chỉ cần sao chép, không phải gõ. Chỉ làm một lần cho mỗi cửa hàng.

⚡ Ngắn gọn — đã quen công nghệ

  1. Yêu cầu token (nút bên dưới) → token gửi vào Chat/Trợ giúp.
  2. Cài Termux + Termux:Boot từ F-Droid (không phải Play Store), mở Termux:Boot một lần.
  3. Dán vào Termux:
    apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash
  4. Chọn ngôn ngữ → dán token → đợi Relay Agent trực tuyến.
  5. Mỗi TV: Developer options › Network debugging BẬT → trong Termux (NEW SESSION) gõ nexbill-tv <IP TV> → Allow trên TV (tích Always allow).
    nexbill-tv 192.168.1.50
  6. Điện thoại: pin Termux "Không hạn chế", khóa Termux trong Ứng dụng gần đây, thông báo Termux → Acquire wakelock.
  7. Điều khiển thiết bị › Thêm thiết bị › TV (Android/Google TV) › nhập tên & IP TV → Lưu → thử Bật/Tắt.

0Chuẩn bị điện thoại

  • Android 7 trở lên — nên là điện thoại cũ dành riêng cho việc này, không phải điện thoại cá nhân mang về nhà.
  • Kết nối CÙNG WiFi với TV ở cửa hàng và luôn để ở cửa hàng.
  • Luôn cắm sạc; màn hình có thể tắt.

1Yêu cầu Token

Nhấn nút bên dưới. Token được gửi vào menu Chat/Trợ giúp. Mở menu đó trên điện thoại sẽ dùng để dễ sao chép token.

2Cài ứng dụng Termux và Termux:Boot

Từng cài Termux từ Play Store? Hãy gỡ cài đặt trước. Bản trên Play Store đã cũ và không dùng được với Termux:Boot từ F-Droid.

  1. Trên điện thoại sẽ dùng, mở liên kết Termux bên dưới bằng Chrome.

    Termux: https://f-droid.org/packages/com.termux/
    Termux:Boot: https://f-droid.org/packages/com.termux.boot/

  2. Cuộn đến mục "Packages" rồi bấm "Download APK" ở phiên bản TRÊN CÙNG. Đừng bấm nút lớn "Download F-Droid".
  3. Khi tải xong, bấm "Mở" (hoặc mở tệp .apk từ thông báo / thư mục Download).
  4. Nếu hiện "Vì lý do bảo mật, điện thoại không được phép cài ứng dụng không rõ nguồn từ nguồn này": bấm Cài đặt, bật "Cho phép từ nguồn này", rồi quay lại và bấm Cài đặt.
  5. Nếu Google Play Protect cảnh báo, chọn "Thêm chi tiết" → "Vẫn cài đặt". Termux từ F-Droid là ứng dụng chính thức, an toàn.
  6. Lặp lại các bước tương tự cho Termux:Boot (liên kết thứ hai).
  7. Mở ứng dụng Termux:Boot MỘT lần (mở rồi đóng), sau đó mở Termux và đợi đến khi dấu $ hiện trên màn hình đen.

3Sao chép một lệnh vào Termux

Nhấn Sao chép bên dưới. Mở Termux, nhấn giữ trên màn hình đen, chọn Paste, rồi nhấn Enter. Đợi 2–5 phút đến khi hiện lựa chọn ngôn ngữ. Nếu hỏi "Do you want to continue? [Y/n]", gõ y rồi Enter.

apt update && yes | apt full-upgrade && apt install -y curl && curl -fsSL https://www.nexbill.id/downloads/nexbill-agent/android/install.sh | bash

Xong khi hiện "[5/5]" rồi đến "Choose language". Thấy "WARNING: apt does not have a stable CLI interface"? Đó là bình thường — bỏ qua.

4Chọn ngôn ngữ và dán token

  1. Trong Termux gõ số ngôn ngữ rồi nhấn Enter (6 = Tiếng Việt).
  2. Lấy token: mở NEXBILL bằng Chrome trên điện thoại này → menu Chat/Trợ giúp → tin nhắn chứa token → nhấn giữ đoạn token → Sao chép.
  3. Quay lại Termux (vẫn hiện "Nhập Agent Token"), nhấn giữ màn hình đen → Paste → Enter.
  4. Thành công khi hiện "Đã kết nối … Đang chờ lệnh từ NEXBILL" và trạng thái Relay Agent trên trang này chuyển sang trực tuyến.

5Kết nối từng TV (mỗi TV một lần)

  1. Trên TV: Settings → Device Preferences (hoặc System) → About → bấm dòng "Build" 7 lần đến khi hiện "You are now a developer".
  2. Quay lại Device Preferences → Developer options → bật "Network debugging" (hoặc "ADB debugging"). Ghi lại IP của TV — thường hiện bên dưới, vd. 192.168.1.23. Không thấy? Xem ở Settings → Network & Internet → tên WiFi.
  3. Trên điện thoại: mở Termux, vuốt từ mép TRÁI màn hình → bấm NEW SESSION, rồi gõ lệnh bên dưới với IP TV của bạn và nhấn Enter.
    nexbill-tv 192.168.1.50
  4. Nhìn màn hình TV: hiện "Allow USB debugging?" / "Allow network debugging?" — tích "Always allow from this computer", rồi chọn Allow/OK. Lặp lại Bước 5 cho từng TV.

Thay 192.168.1.50 bằng IP TV của bạn. Thành công nếu có chữ "device" cạnh IP TV.

6Để điện thoại không tắt ứng dụng (quan trọng!)

  • Cài đặt → Ứng dụng → Termux → Pin → chọn "Không hạn chế" / "Unrestricted". Làm tương tự với Termux:Boot.
  • Mở danh sách ứng dụng gần đây, nhấn giữ Termux và chọn Khóa (biểu tượng ổ khóa) để không bị đóng khi "Xóa tất cả".
  • Đừng xóa thông báo của Termux — đó là dấu hiệu agent đang chạy.
  • Kéo bảng thông báo xuống, tìm thông báo Termux rồi bấm "Acquire wakelock" để điện thoại không cho agent ngủ khi tắt màn hình.
  • Xiaomi / Redmi / POCO: Cài đặt → Ứng dụng → Quản lý ứng dụng → Termux → bật "Tự khởi chạy", rồi Tiết kiệm pin → "Không hạn chế".
  • OPPO / realme / vivo: Cài đặt → Ứng dụng → Termux → Mức sử dụng pin → bật "Cho phép hoạt động nền" và "Cho phép tự khởi chạy".
  • Samsung: Cài đặt → Ứng dụng → Termux → Pin → "Không hạn chế". Đảm bảo Termux không nằm trong "Ứng dụng ngủ" ở Cài đặt → Pin → Giới hạn sử dụng nền.

7Thêm TV trong NEXBILL

Quay lại trang này, nhấp "Thêm thiết bị", chọn giao thức "TV (Android/Google TV)", nhập tên và IP của TV từ Bước 5, rồi Lưu. Xong — TV có thể được bật/tắt từ dashboard này.

✓ Cách kiểm tra mọi thứ hoạt động

  • Trên trang này, trạng thái Relay Agent là trực tuyến.
  • Điện thoại có thông báo Termux ("1 session"). Nếu mất, mở Termux và gõ nexbill.
  • Trong danh sách thiết bị bên dưới, nút Bật/Tắt của TV thật sự bật và tắt TV.

⚠ Nếu gặp sự cố

  • Hiện "CANNOT LINK EXECUTABLE curl" hoặc "cannot locate symbol": gói Termux chưa được cập nhật hết. Trong Termux gõ: apt update && yes | apt full-upgrade — đợi xong rồi dán lại lệnh ở Bước 3.
  • Relay Agent "ngoại tuyến": mở Termux, gõ nexbill rồi Enter.
  • TV không phản hồi: kiểm tra TV đang bật/chờ và cùng WiFi, rồi trong Termux gõ nexbill-tv kèm IP TV.
  • Sau khi khởi động lại điện thoại, agent tự chạy (Termux:Boot). Nếu không, mở Termux và gõ nexbill.
  • Agent tự động cập nhật (kiểm tra mỗi 6 giờ, cài lúc 03:00–06:00). Muốn có bản mới nhất ngay? Trong Termux gõ nexbill-update — không cần nhập lại token.
  • Vẫn chưa được? Gửi ảnh chụp màn hình Termux vào menu Chat/Trợ giúp — đội NEXBILL sẽ hỗ trợ.
