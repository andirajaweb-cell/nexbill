NEXBILL TV — Aplikasi NEXBILL TV (paling mudah)

Cara paling mudah untuk Android TV / Google TV: pasang aplikasi NEXBILL TV langsung di TV. Tidak perlu PC, HP, Developer options, atau ADB. Saat sesi dimulai, TV menampilkan game dari HDMI dengan timer di pojok. Saat waktu habis, layar ditutup halaman NEXBILL dan suara game berhenti.

⚡ Ringkas — sudah paham teknologi

  1. TV: Google Play → pasang Downloader (AFTVnews) → buka → ketik nexbill.id/tvapk → Install (izinkan Unknown sources untuk Downloader).
  2. Dashboard: Feature Management › TV Screensaver ON · unit tipe TV = Android TV · Pengaturan › TV Screensaver › tambah layar → kode 6 digit (30 menit).
  3. Buka NEXBILL TV → ketik kode.
  4. OK → PIN kasir → "Pengaturan TV (menu staf)" → "Pilih input HDMI" konsol → "Izin tampil di atas aplikasi lain" (penjaga layar) → "Jadikan aplikasi utama TV".
  5. Tes sesi 5 menit di kasir: game + timer tampil, tekan Home → kembali ke game ±1 detik, waktu habis → layar terkunci & suara berhenti.

Yang perlu disiapkan

  • TV Android TV / Google TV (TV pintar yang punya Google Play). TV biasa tanpa Google Play memakai smart plug.
  • TV tersambung ke WiFi/internet outlet, dan PlayStation dicolok ke salah satu lubang HDMI TV.
  • Remote TV, dan dashboard NEXBILL terbuka di HP/PC kasir (untuk membuat kode pairing).

1Pasang aplikasi NEXBILL TV di TV

  1. Di TV, buka Google Play (ikon segitiga warna-warni). Pilih kaca pembesar (Cari), ketik "Downloader" dengan remote atau tombol mikrofon.
  2. Pilih aplikasi "Downloader" (logo oranye, by AFTVnews) → Instal → Buka. Kalau ditanya izin akses file, pilih Izinkan.
  3. Di kotak alamat Downloader, ketik persis: nexbill.id/tvapk lalu tekan Go.
  4. Kalau muncul pesan pemasangan diblokir, pilih Settings/Setelan → nyalakan Downloader ("Izinkan dari sumber ini" / "Unknown sources") → tekan Back.
  5. Pilih Install, tunggu sampai selesai, lalu pilih Done. Kalau Downloader menawarkan menghapus file pemasang, pilih Delete (aplikasinya tetap ada).

2Buat kode pairing di dashboard

  1. Pengaturan › Feature Management: pastikan TV Screensaver aktif.
  2. Rental PS › Kelola Unit: tipe TV unit itu = Android TV.
  3. Pengaturan › TV Screensaver → tambah layar untuk unit itu → catat kode 6 angka yang muncul. Kode berlaku 30 menit.

3Ketik kode di TV

  1. Di TV, buka aplikasi NEXBILL TV (ada di deretan aplikasi). Layar menampilkan kotak kode.
  2. Ketik 6 angka dengan tombol angka di remote (atau keyboard di layar), lalu OK. Berhasil kalau tampil layar NEXBILL dengan nama unit.

4Pilih HDMI tempat PlayStation dicolok (sekali saja)

  1. Tekan OK atau Menu di remote → isi PIN kasir → Panel kasir → "Pengaturan TV (menu staf)". Sebelum TV dipasangkan, menu staf dibuka dengan menahan OK 3 detik.
  2. Pilih "Pilih input HDMI", lalu pilih HDMI tempat PlayStation dicolok (mis. HDMI 2).
  3. Coba di menu staf: "Buka layar game 10 menit (tes, tanpa tagihan)". Gambar PlayStation harus tampil dengan timer di pojok kanan atas, lalu pilih "Akhiri mode staf".

5Aktifkan penjaga layar (wajib)

  1. Menu staf → "Izin tampil di atas aplikasi lain" → izinkan NEXBILL TV. Penjaga layar (aktif sejak awal) lalu mengembalikan NEXBILL TV ke depan dalam sekitar 1 detik bila tombol Home, tombol input/source, atau aplikasi lain dipakai — pelanggan tidak bisa main tanpa sesi atau melewati waktu habis.
  2. Lalu menu staf → "Jadikan aplikasi utama TV" → pilih NEXBILL TV, agar TV yang baru dinyalakan langsung membuka NEXBILL TV. Sebagian merek TV tidak menyediakan pilihan ini; penjaga layar tetap bekerja.
  3. TV juga dipakai untuk keperluan lain? Menu staf → "Penjaga layar" untuk mematikannya. Membuka Pengaturan TV dari menu staf menjeda penjaga selama 10 menit.

6Tes dengan sesi pendek

  1. Di Rental PS, mulai sesi 5 menit untuk unit itu. TV harus menampilkan PlayStation dan timer.
  2. Saat waktu habis, layar NEXBILL menutup game dan suara game berhenti. Selesai — ulangi Langkah 1–6 untuk TV berikutnya.

Fungsi menu di TV (panel kasir & menu staf)

Setelah TV terhubung: tekan OK atau Menu di remote → isi PIN kasir → Panel kasir. Menu staf ada di Panel kasir › "Pengaturan TV (menu staf)". Setiap pilihan di TV punya keterangan singkat, dan "Petunjuk menu ini" berisi urutan setup.

Panel kasir

  • Mulai sesi — pilih paket, durasi, atau Bebas. Layar game terbuka, argo berjalan, tagihan masuk ke Kasir (Order Terbuka).
  • Tambah waktu — 15 menit sampai 2 jam untuk sesi berdurasi.
  • Akhiri sesi sekarang — argo berhenti, layar game terkunci dan TV menampilkan "Sesi selesai", pelanggan bayar di kasir.
  • Status sinkron — aksi dari TV yang belum/gagal terkirim ke dashboard. Saat internet putus semuanya tetap jalan dan dikirim otomatis begitu online.

Menu staf (Pengaturan TV)

  • Buka layar game 10 menit — tes gambar, suara & stik tanpa sesi dan tanpa tagihan; maks. 3 kali sehari, tercatat di dashboard.
  • Pilih input HDMI — colokan HDMI tempat PlayStation terpasang.
  • Mode tampilan HDMI — "Di dalam aplikasi" (disarankan). "Pindah input TV" hanya bila gambar PS tidak muncul di aplikasi.
  • Izin tampil di atas aplikasi lain — wajib untuk penjaga layar dan mode Pindah input TV.
  • Jadikan aplikasi utama TV — NEXBILL TV terbuka sendiri saat TV menyala atau tombol Home ditekan.
  • Penjaga layar — tombol Home, Source, atau aplikasi lain tidak bisa dipakai untuk main tanpa sesi. Matikan hanya bila TV dipakai keperluan lain.
  • Muat ulang layar — bila screensaver macet, tidak berubah, atau kosong.
  • Cek pembaruan aplikasi — membandingkan versi terpasang dengan versi terbaru di nexbill.id.
  • Info perangkat — versi, outlet & unit yang terhubung, input HDMI, mode, dan izin.

⚠ Kalau ada masalah

  • Gambar game tidak muncul ("menunggu sinyal"): pastikan PlayStation menyala dan HDMI-nya benar, lalu pilih ulang input di menu staf. Kalau TV tidak mengizinkan HDMI tampil di dalam aplikasi, NEXBILL TV pindah sendiri ke mode "Pindah input TV" — izinkan "Tampil di atas aplikasi lain" lewat menu staf.
  • Kode ditolak: kode berlaku 30 menit dan hanya sekali pakai. Buat kode baru di Pengaturan › TV Screensaver.
  • TV kembali menampilkan kotak kode: layar itu dihapus atau dilepas di dashboard. Buat kode baru lalu ketik lagi.
  • Downloader tidak bisa membuka nexbill.id/tvapk: pastikan TV tersambung internet dan alamat diketik tanpa spasi. Masih gagal? Kirim foto layar TV ke menu Chat/Bantuan.

Memperbarui aplikasi: di TV tekan OK → PIN kasir → "Pengaturan TV (menu staf)" → "Cek pembaruan aplikasi". Kalau ada versi baru, buka Downloader dan ketik nexbill.id/tvapk lagi — pairing dan pengaturan tetap tersimpan.

NEXBILL TV — NEXBILL TV app (easiest)

The easiest way for Android TV / Google TV: install the NEXBILL TV app directly on the TV. No PC, phone, Developer options, or ADB needed. When a session starts, the TV shows the game from HDMI with a timer in the corner. When time runs out, the NEXBILL screen covers it and the game sound stops.

⚡ Quick — already tech-savvy

  1. TV: Google Play → install Downloader (AFTVnews) → open → type nexbill.id/tvapk → Install (allow Unknown sources for Downloader).
  2. Dashboard: Feature Management › TV Screensaver ON · unit TV type = Android TV · Settings › TV Screensaver › add screen → 6-digit code (30 min).
  3. Open NEXBILL TV → type the code.
  4. OK → cashier PIN → "TV settings (staff menu)" → "Choose HDMI input" for the console → "Display over other apps" (screen guard) → "Make this the main TV app".
  5. Test a 5-minute session at the cashier: game + timer show, press Home → back to the game in ~1 s, time up → screen locks & sound stops.

What you need

  • An Android TV / Google TV (a smart TV with Google Play). Regular TVs without Google Play use a smart plug.
  • The TV is connected to the outlet WiFi/internet, and the PlayStation is plugged into one of the TV's HDMI ports.
  • The TV remote, and the NEXBILL dashboard open on the cashier phone/PC (to create the pairing code).

1Install the NEXBILL TV app on the TV

  1. On the TV, open Google Play (the colourful triangle icon). Choose the magnifier (Search) and type "Downloader" with the remote or the microphone button.
  2. Choose the "Downloader" app (orange logo, by AFTVnews) → Install → Open. If it asks for file access, choose Allow.
  3. In Downloader's address box, type exactly: nexbill.id/tvapk then press Go.
  4. If a message says installation is blocked, choose Settings → turn on Downloader ("Allow from this source" / "Unknown sources") → press Back.
  5. Choose Install, wait until it finishes, then choose Done. If Downloader offers to delete the installer file, choose Delete (the app stays).

2Create a pairing code in the dashboard

  1. Settings › Feature Management: make sure TV Screensaver is on.
  2. PS Rental › Manage Units: that unit's TV type = Android TV.
  3. Settings › TV Screensaver → add a screen for that unit → note the 6-digit code shown. The code is valid for 30 minutes.

3Type the code on the TV

  1. On the TV, open the NEXBILL TV app (in the apps row). The screen shows a code box.
  2. Type the 6 digits with the remote's number buttons (or the on-screen keyboard), then OK. It worked when the NEXBILL screen shows the unit name.

4Choose the HDMI port the PlayStation uses (once)

  1. Press OK or Menu on the remote → enter the cashier PIN → Cashier panel → "TV settings (staff menu)". Before the TV is paired, open the staff menu by holding OK for 3 seconds.
  2. Choose "Choose HDMI input", then pick the HDMI port the PlayStation is plugged into (e.g. HDMI 2).
  3. Try it from the staff menu: "Open game screen 10 minutes (test, no bill)". The PlayStation picture should appear with a timer in the top-right corner; then choose "End staff mode".

5Turn on the screen guard (required)

  1. Staff menu → "Display over other apps" → allow NEXBILL TV. The screen guard (on from the start) then brings NEXBILL TV back to the front in about 1 second whenever the Home button, the input/source button, or another app is used — customers can't play without a session or past time-up.
  2. Then staff menu → "Make this the main TV app" → choose NEXBILL TV, so a freshly switched-on TV opens NEXBILL TV straight away. Some TV brands don't offer this option; the screen guard still works.
  3. TV also used for other things? Staff menu → "Screen guard" to turn it off. Opening TV Settings from the staff menu pauses the guard for 10 minutes.

6Test with a short session

  1. In PS Rental, start a 5-minute session for that unit. The TV should show the PlayStation and the timer.
  2. When time is up, the NEXBILL screen covers the game and the game sound stops. Done — repeat Steps 1–6 for the next TV.

What the TV menus do (cashier panel & staff menu)

Once the TV is paired: press OK or Menu on the remote → enter the cashier PIN → Cashier panel. The staff menu is in Cashier panel › "TV settings (staff menu)". Every option on the TV has a short description, and "Help for this menu" shows the setup order.

Cashier panel

  • Start session — choose a package, duration, or Open. The game screen opens, the timer runs, and the bill goes to the Cashier (Open Orders).
  • Add time — 15 minutes to 2 hours for timed sessions.
  • End session now — the timer stops, the game screen locks and the TV shows "Session ended"; the customer pays at the cashier.
  • Sync status — actions from the TV not yet sent or rejected by the dashboard. When the internet is down everything keeps working and is sent automatically once online.

Staff menu (TV settings)

  • Open game screen for 10 minutes — test picture, sound & controllers with no session and no bill; max 3 times a day, logged in the dashboard.
  • Choose HDMI input — the HDMI port the PlayStation is plugged into.
  • HDMI display mode — "Inside the app" (recommended). "Switch TV input" only if the PS picture does not appear in the app.
  • Display over other apps — required for the screen guard and Switch TV input mode.
  • Make it the TV's main app — NEXBILL TV opens by itself when the TV turns on or Home is pressed.
  • Screen guard — Home, Source or other apps cannot be used to play without a session. Turn it off only if the TV is also used for other things.
  • Reload screen — if the screensaver is stuck, not updating, or blank.
  • Check for app update — compares the installed version with the latest on nexbill.id.
  • Device info — version, connected outlet & unit, HDMI input, mode, and permissions.

⚠ If something goes wrong

  • No game picture ("waiting for signal"): make sure the PlayStation is on and the HDMI is correct, then choose the input again in the staff menu. If the TV does not allow HDMI inside apps, NEXBILL TV switches itself to "Switch TV input" mode — allow "Display over other apps" from the staff menu.
  • Code rejected: the code is valid for 30 minutes and works once. Create a new code in Settings › TV Screensaver.
  • The TV shows the code box again: that screen was removed or reset in the dashboard. Create a new code and type it again.
  • Downloader cannot open nexbill.id/tvapk: make sure the TV has internet and the address has no spaces. Still failing? Send a photo of the TV screen to the Chat/Help menu.

Updating the app: on the TV press OK → cashier PIN → "TV settings (staff menu)" → "Check for app update". If there is a new version, open Downloader and type nexbill.id/tvapk again — pairing and settings are kept.

NEXBILL TV — NEXBILL TV app (pinakamadali)

Ang pinakamadaling paraan para sa Android TV / Google TV: i-install ang NEXBILL TV app mismo sa TV. Hindi kailangan ng PC, phone, Developer options, o ADB. Kapag nagsimula ang session, ipapakita ng TV ang laro mula sa HDMI na may timer sa sulok. Kapag naubos ang oras, tatakpan ito ng NEXBILL screen at titigil ang tunog ng laro.

⚡ Maikli — sanay na sa teknolohiya

  1. TV: Google Play → i-install ang Downloader (AFTVnews) → buksan → i-type ang nexbill.id/tvapk → Install (payagan ang Unknown sources para sa Downloader).
  2. Dashboard: Feature Management › TV Screensaver ON · uri ng TV ng unit = Android TV · Settings › TV Screensaver › magdagdag ng screen → 6-digit code (30 min).
  3. Buksan ang NEXBILL TV → i-type ang code.
  4. OK → PIN ng cashier → "Settings ng TV (staff menu)" → "Piliin ang HDMI input" ng console → "Ipakita sa ibabaw ng ibang app" (screen guard) → "Gawing pangunahing app ng TV".
  5. Subukan ang 5-minutong session sa kahera: lalabas ang laro + timer, pindutin ang Home → balik sa laro sa ~1 s, ubos ang oras → naka-lock ang screen at tumigil ang tunog.

Ang kailangan

  • Android TV / Google TV (smart TV na may Google Play). Ang karaniwang TV na walang Google Play ay gumagamit ng smart plug.
  • Nakakonekta ang TV sa WiFi/internet ng outlet, at nakasaksak ang PlayStation sa isa sa HDMI port ng TV.
  • Remote ng TV, at bukas ang NEXBILL dashboard sa phone/PC ng cashier (para gumawa ng pairing code).

1I-install ang NEXBILL TV app sa TV

  1. Sa TV, buksan ang Google Play (makulay na tatsulok na icon). Piliin ang magnifier (Search) at i-type ang "Downloader" gamit ang remote o mikropono.
  2. Piliin ang "Downloader" app (orange na logo, by AFTVnews) → Install → Open. Kapag humingi ng access sa file, piliin ang Allow.
  3. Sa address box ng Downloader, i-type nang eksakto: nexbill.id/tvapk saka pindutin ang Go.
  4. Kapag may mensaheng naka-block ang pag-install, piliin ang Settings → i-on ang Downloader ("Allow from this source" / "Unknown sources") → pindutin ang Back.
  5. Piliin ang Install, hintaying matapos, saka piliin ang Done. Kapag inalok ng Downloader na burahin ang installer, piliin ang Delete (mananatili ang app).

2Gumawa ng pairing code sa dashboard

  1. Settings › Feature Management: siguraduhing naka-on ang TV Screensaver.
  2. PS Rental › Pamahalaan ang Unit: ang uri ng TV ng unit = Android TV.
  3. Settings › TV Screensaver → magdagdag ng screen para sa unit → itala ang 6-digit code. Valid ang code nang 30 minuto.

3I-type ang code sa TV

  1. Sa TV, buksan ang NEXBILL TV app (nasa hanay ng apps). May code box sa screen.
  2. I-type ang 6 na digit gamit ang number buttons ng remote (o on-screen keyboard), saka OK. Tagumpay kapag ipinakita ng NEXBILL screen ang pangalan ng unit.

4Piliin ang HDMI kung saan nakasaksak ang PlayStation (isang beses)

  1. Pindutin ang OK o Menu sa remote → ilagay ang PIN ng cashier → Cashier panel → "Settings ng TV (staff menu)". Bago ma-pair ang TV, buksan ang staff menu sa pagpindot nang matagal ng OK nang 3 segundo.
  2. Piliin ang "Piliin ang HDMI input", saka piliin ang HDMI na may PlayStation (hal. HDMI 2).
  3. Subukan mula sa staff menu: "Buksan ang game screen nang 10 minuto (test, walang bayad)". Dapat lumabas ang PlayStation na may timer sa kanang itaas, saka piliin ang "Tapusin ang staff mode".

5I-on ang screen guard (kailangan)

  1. Staff menu → "Ipakita sa ibabaw ng ibang app" → payagan ang NEXBILL TV. Ibabalik ng screen guard (naka-on mula sa simula) ang NEXBILL TV sa harap sa loob ng mga 1 segundo kapag ginamit ang Home button, input/source button, o ibang app — hindi makakapaglaro ang customer nang walang session o lampas sa oras.
  2. Saka staff menu → "Gawing pangunahing app ng TV" → piliin ang NEXBILL TV, para direktang bumukas ang NEXBILL TV sa bagong buhay na TV. Walang ganitong opsyon ang ilang brand ng TV; gumagana pa rin ang screen guard.
  3. Ginagamit din ang TV sa ibang bagay? Staff menu → "Screen guard" para i-off. Ang pagbukas ng TV Settings mula sa staff menu ay nagpo-pause sa guard nang 10 minuto.

6Subukan gamit ang maikling session

  1. Sa PS Rental, magsimula ng 5-minutong session para sa unit. Dapat ipakita ng TV ang PlayStation at ang timer.
  2. Kapag tapos na ang oras, tatakpan ng NEXBILL screen ang laro at titigil ang tunog. Tapos — ulitin ang Hakbang 1–6 para sa susunod na TV.

Gamit ng mga menu sa TV (cashier panel at staff menu)

Kapag naka-pair na ang TV: pindutin ang OK o Menu sa remote → ilagay ang PIN ng cashier → Cashier panel. Nasa Cashier panel › "Settings ng TV (staff menu)" ang staff menu. May maikling paliwanag ang bawat opsyon sa TV, at nasa "Gabay sa menu na ito" ang pagkakasunod ng setup.

Cashier panel

  • Simulan ang session — pumili ng package, tagal, o Bukas. Bubukas ang game screen, tatakbo ang oras, at papasok ang bill sa Cashier (Open Orders).
  • Magdagdag ng oras — 15 minuto hanggang 2 oras para sa may tagal na session.
  • Tapusin ang session ngayon — hihinto ang oras, mala-lock ang game screen at ipapakita ng TV ang "Tapos na ang session"; magbabayad ang customer sa cashier.
  • Status ng sync — mga aksyon mula sa TV na hindi pa naipadala o tinanggihan ng dashboard. Kapag walang internet, tuloy pa rin ang lahat at kusang ipapadala pagka-online.

Staff menu (TV settings)

  • Buksan ang game screen nang 10 minuto — subukan ang larawan, tunog at controller nang walang session at bayad; hanggang 3 beses kada araw, naitatala sa dashboard.
  • Pumili ng HDMI input — ang HDMI port kung saan nakasaksak ang PlayStation.
  • HDMI display mode — "Sa loob ng app" (inirerekomenda). "Palitan ang input ng TV" kung hindi lumalabas ang larawan ng PS sa app lang.
  • Magpakita sa ibabaw ng ibang app — kailangan para sa bantay ng screen at mode na Palitan ang input ng TV.
  • Gawing pangunahing app ng TV — kusang bubukas ang NEXBILL TV pag-on ng TV o pagpindot ng Home.
  • Bantay ng screen — hindi magagamit ang Home, Source o ibang app para maglaro nang walang session. I-off lang kung ginagamit din ang TV sa ibang bagay.
  • I-reload ang screen — kapag naka-stuck, hindi nagbabago, o blangko ang screensaver.
  • Tingnan ang update ng app — inihahambing ang naka-install na bersyon sa pinakabago sa nexbill.id.
  • Info ng device — bersyon, nakakonektang outlet at unit, HDMI input, mode, at mga pahintulot.

⚠ Kapag may problema

  • Walang larawan ng laro ("naghihintay ng signal"): siguraduhing naka-on ang PlayStation at tama ang HDMI, saka piliin ulit ang input sa staff menu. Kung hindi pinapayagan ng TV ang HDMI sa loob ng app, kusang lilipat ang NEXBILL TV sa "Palitan ang input ng TV" mode — payagan ang "Ipakita sa ibabaw ng ibang app" sa staff menu.
  • Tinanggihan ang code: valid nang 30 minuto at isang beses lang magagamit. Gumawa ng bago sa Settings › TV Screensaver.
  • Bumalik sa code box ang TV: inalis o ni-reset ang screen sa dashboard. Gumawa ng bagong code at i-type ulit.
  • Hindi mabuksan ng Downloader ang nexbill.id/tvapk: siguraduhing may internet ang TV at walang espasyo ang address. Hindi pa rin? Magpadala ng larawan ng TV screen sa Chat/Tulong.

Pag-update ng app: sa TV pindutin ang OK → PIN ng cashier → "Settings ng TV (staff menu)" → "Tingnan ang update ng app". Kapag may bagong bersyon, buksan ang Downloader at i-type ulit ang nexbill.id/tvapk — mananatili ang pairing at settings.
